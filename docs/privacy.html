プライバシーポリシー

制定日: 2026年8月7日 / 最終改定日: 2026年10月3日

本ポリシーは、将棋Vault(以下「本アプリ」)における利用者情報の取り扱いについて定めるものです。

1. 収集する情報

本アプリは、利用者が任意でアカウント連携(「2-3. アカウント連携と複数端末の同期について」)を利用した場合に限り、サインインに必要なメールアドレス等の情報を取り扱います。 アカウント連携を利用しない場合、本アプリが氏名・メールアドレス等、利用者を直接特定できる個人情報を取得することはありません。 また、後述する広告配信機能に伴い、第三者(Google)が提供するSDKを通じて一部の情報が処理されます。詳細は「4. 広告配信について」をご覧ください。

2. 棋譜・研究データの取り扱い

本アプリで作成する研究・変化ツリー・コメント等のデータ(棋譜本体)は、利用者の端末内(ローカルデータベース)にのみ保存され、外部サーバーへ送信されることはありません。 アカウント連携を利用した場合も、同期の対象は設定・進捗データに限られ、棋譜本体は含まれません(「2-3.」参照)。AI解析は端末内蔵のエンジンで完結し、 解析のために局面や棋譜をクラウドや外部APIへ送信することはありません。この取り扱いは、後述する広告配信機能の有無にかかわらず変わりません。

2-2. 評価関数ファイルのダウンロードについて

本アプリは、AI解析に使う評価関数(将棋AIの強さを決めるデータファイル)を切り替える機能を備えています。 標準の評価関数はアプリに同梱されており、通信は発生しません。

利用者が設定画面で追加の評価関数を選んでダウンロードを実行した場合に限り、本アプリは GitHub (GitHub, Inc. が運営するソフトウェア配布サービス)へHTTPS通信を行い、評価関数ファイルを取得します。

  • この通信で送信されるのは、ファイルの取得要求のみです。棋譜・研究データ・解析結果・その他の利用者情報は一切送信しません。
  • 通信の性質上、接続元のIPアドレスやアクセス日時はGitHub側に記録されます。これはファイルをダウンロードする際に不可避な情報です。
  • ダウンロードは利用者が明示的に操作したときにのみ行われ、自動的に実行されることはありません。
  • ダウンロードした評価関数は端末内にのみ保存され、外部へ送信されることはありません。

取得先: https://github.com/irep-takeshi-maya/shogi-vault-gpl-source/releases

2-3. アカウント連携と複数端末の同期について

本アプリは、複数の端末で設定や進捗を引き継ぐための任意のアカウント連携機能を備えています。 アカウント連携を利用しなくても、本アプリのすべての機能をこれまでどおり利用できます。

利用者がサインインした場合に限り、本アプリは Google LLC が提供する Firebase(Firebase Authentication および Cloud Firestore)を利用して、以下の情報を取り扱います。

  • 認証に使う情報: メールアドレス、Firebase が発行する利用者ID、サインイン方法(Appleでサインイン/Googleでサインイン/メールアドレスとパスワード)。Apple または Google でサインインした場合は、各社から提供される識別子とメールアドレスを受け取ります。パスワードは Firebase Authentication が管理し、アプリ運営者が知ることはありません。
  • 同期するデータ: 端末に依存しない設定(テーマ・駒の書体・解析の深さ等)、戦型ポートフォリオ・未到マップの進捗、AI対局の段位別進捗。
  • 同期しないデータ: 研究・棋譜・変化ツリー・コメント等の棋譜本体、端末ごとのエンジン設定、ダウンロードした評価関数。
  • 保存場所: 同期データは Cloud Firestore の東京リージョン(asia-northeast1)に保存されます。認証情報は Firebase Authentication により Google のデータセンター(日本国外を含む)で管理されます。
  • アクセスできる人: 同期データは、サインインした本人だけが読み書きできるよう制限しています。
  • 送信のタイミング: サインイン時と、利用者が「今すぐ同期」を実行したときに限ります。
  • 保存期間と削除: 同期データと認証情報は、利用者がアカウントを削除するまで保存されます。アプリ内の「アカウント」画面からいつでもアカウントを削除でき、その際、サーバー上の同期データもあわせて削除されます。端末内のデータは削除されません。アプリから削除できない場合は、「9. お問い合わせ」の連絡先までご依頼ください。
  • 利用目的: 同期データは複数端末間の引き継ぎのためにのみ使用し、分析・広告・その他の目的には使用しません。

Firebase における情報の取り扱いについては、Google社のプライバシーポリシーおよび Firebase のプライバシーに関する情報をご確認ください: https://firebase.google.com/support/privacy

2-4. Proプラン(アプリ内課金)について

本アプリの有料プラン「Pro」の購入・購読・復元は、Apple社の App Store または Google社の Google Play の決済機能を通じて行われます。 決済情報(クレジットカード番号等)は各ストアが管理し、本アプリおよびアプリ運営者が取得することはありません。

本アプリは、Pro が有効かどうかを、端末上でストアの購入情報を参照して判定し、その結果を端末内にのみ保存します。購入情報をアプリ運営者のサーバーへ送信することはありません。 Pro を購入した利用者には、対局モードのリワード広告を表示しません。

3. 第三者への提供

本アプリは、棋譜・研究データ等の利用者作成コンテンツを第三者へ提供することはありません。 アカウント連携を利用した場合の同期データ・認証情報は、上記「2-3.」のとおり、保存先として Google社(Firebase)が提供する基盤で取り扱われますが、本アプリがこれらを第三者へ販売・提供することはありません。 一方で、広告配信のために組み込んでいるGoogle社のSDK(下記4.参照)は、広告の表示・配信に必要な範囲で情報をGoogle社へ送信します。これは本アプリが独自に第三者へ情報提供を行っているものではなく、 広告SDKの動作上不可避な通信です。

4. 広告配信について

本アプリは、対局モードの「まった(2回目以降)」「AI HELP」機能を利用する際に限り、Google社の広告配信サービス「Google AdMob」によるリワード広告(動画視聴型の任意広告)を表示します。 研究・解析・棋譜閲覧など、対局モード以外の画面には広告を一切表示しません。バナー広告や強制表示型の広告(インタースティシャル広告)も使用していません。

本アプリが配信する広告は非パーソナライズ広告(利用者の興味関心に基づかない広告)に限定して設定しており、 Apple社の「App Tracking Transparency(ATT)」による許諾確認は行っていません(本アプリはOS標準のトラッキング識別子(IDFA)を利用しないため)。

ただし、広告SDKの技術的な仕組み上、Google AdMobは広告の表示・配信・不正防止・利用状況の集計を目的として、以下のような情報を処理する場合があります(Google社が公開する開発者向け情報に基づく)。

  • 広告リクエストの送信に伴う、おおまかな位置情報(IPアドレスに基づく)
  • 端末の識別子(広告ID等。非パーソナライズ広告のためユーザーの興味関心の推定・広告のパーソナライズには使用されません)
  • アプリの起動・広告の表示や視聴といった操作に関する情報
  • クラッシュログ・パフォーマンスデータ等の診断情報

これらの情報の具体的な取り扱いについては、Google社のプライバシーポリシーをご確認ください: https://policies.google.com/privacy

5. アフィリエイトリンクについて

本アプリの「棋書紹介」ページには、Amazonアソシエイト・プログラムおよび楽天アフィリエイトを利用した書籍紹介リンクを掲載しています。 利用者がこれらのリンクを経由して商品を購入された場合、アプリ運営者が紹介料を得ることがあります(利用者が支払う価格が変わることはありません)。

リンク先である Amazon.co.jp・楽天市場は本アプリの管理外の第三者サービスであり、リンク先での情報の取り扱いには各社のプライバシーポリシー・利用規約が適用されます。 本アプリ自体は、これらのリンクのクリック・購入に関する情報を取得・保存しません。

6. Cookie・トラッキング技術

本アプリ自体は、Cookie・広告識別子(IDFA等)による利用者の複数アプリ・複数サイトを横断したトラッキングを行いません。 上記4.のとおり広告配信は非パーソナライズ広告に限定しており、Apple社のATT許諾確認画面も表示しません。
